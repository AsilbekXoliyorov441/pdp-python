# PDP Junior — Python dars reja platformasi (13–16 yosh, 4 oy)

Sahifalar tuzilishi: **Bosh sahifa → Oy (bo'lim) → Modul → Dars → Taqdimot**.
Dars sahifasining o'zi ham to'liq dars rejasi (barcha bloklar ketma-ket + o'qituvchi izohlari).

## Ishga tushirish
`index.html` faylini brauzerda (Chrome tavsiya etiladi) oching. Hech narsa o'rnatish shart emas.
Kod slaydlarida Python birinchi marta ishga tushganda internet kerak (~10 MB bir marta yuklanadi).

## Kurs tuzilmasi
| Oy | Modul | Haftalar |
|---|---|---|
| 1 | 1. Python bilan tanishuv · 2. Shartlar va mantiq | 1–4 |
| 2 | 3. Tsikllar · 4. Satrlar va ro'yxatlar | 5–8 |
| 3 | 5. Lug'atlar, kortejlar, to'plamlar · 6. Funksiyalar | 9–12 |
| 4 | 7. Xatolar, fayllar, modullar · 8. OOP va yakuniy loyiha | 13–16 |

Har bir modul: 4 dars (90 daqiqa) + loyiha + 10 savollik test. Jami 32 dars.

## Har bir darsda
- **Dars rejasi** sahifasi: maqsadlar, vaqt rejasi, barcha slaydlar va o'qituvchi izohlari, uy vazifasi, chop etish.
- **Taqdimot**: slaydlar, jonli kod (▶), savollar, mashqlar (maslahat + yechim), doskaga chizish, taymer.

## Taqdimot tugmalari
`→`/`Probel` keyingi · `←` oldingi · `F` to'liq ekran · `N` o'qituvchi izohi · `G` slaydlar ro'yxati ·
`D` chizish · `R` kodni ishga tushirish · `T` taymer · `1-4` savolga javob · `Esc` chiqish

## Fayllar
- `index.html` — kirish sahifasi
- `css/style.css` — dizayn
- `js/app.js` — sahifalar va taqdimot rejimi
- `js/editor.js`, `js/highlight.js`, `js/python.js` — kod muharriri va brauzerdagi Python
- `js/fx.js` + `js/vendor/motion.js` — animatsiyalar (Motion, ya'ni Framer Motion'ning JS versiyasi; loyiha ichida, internetsiz ishlaydi)
- `js/modules/m01.js … m08.js` — **dars kontenti** (o'zgartirish uchun shu fayllarni tahrirlang)
- `KONTENT_FORMATI.md` — yangi dars/slayd qo'shish formati
